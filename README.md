# Knode Brand License

Knode is open source. Its brand is not.

## Knode's licenses

| What | License |
|---|---|
| Code, docs and the `.knode` format, in every Knode repository | [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0) |
| The brand: the names Knode and .knode, logo, icons, Knode Block and Knode Line | [Knode Brand License](LICENSE.md), all rights reserved |
| Geist and Geist Mono, by Vercel | [SIL Open Font License](https://openfontlicense.org) |

The reasons are in [decision 0003](https://github.com/knodemd/handbook/blob/main/decisions/0003-licences.md).

## This repository

It holds the two documents that protect the brand:

| File | What it covers |
|---|---|
| [`LICENSE.md`](LICENSE.md) | The **Knode Brand License 1.0**: the names Knode and .knode, the logo, the app icon, the icons and the Knode Block and Knode Line typefaces. All rights reserved, with the permissions it lists. |
| [`TRADEMARK.md`](TRADEMARK.md) | How to use the name and logo: to talk about Knode or link to it, never to pass as Knode. |

## In short

- **You can** use the logo, unmodified, to talk about Knode or link to it, and use the brand in
  contributions to Knode.
- **You can't** change it, use it in another product, or present something else as Knode.
- **Forks** of the code are welcome under their own name and logo, crediting Knode.

## Using it in a Knode repository

Copy `LICENSE.md` into the repository as `BRAND-LICENSE.md`, and say in its `NOTICE` which files it
covers (logo, icons, fonts).
